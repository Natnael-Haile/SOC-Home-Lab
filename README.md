# SOC Home Lab

## Project Overview

This repository documents my hands-on Security Operations Center (SOC) home lab using Wazuh, an open-source security monitoring and threat detection platform.

The purpose of this project is to develop practical skills in security event monitoring, alert investigation, threat detection, and incident documentation.

## Project Objectives

- Configure a Wazuh-based security monitoring environment.
- Collect and analyze endpoint security events.
- Investigate suspicious authentication and system activity.
- Identify relevant indicators of compromise and security risks.
- Document investigation findings and recommended remediation actions.

## Technologies

- **SIEM:** Wazuh
- **Virtualization:** VirtualBox
- **Operating Systems:** Windows, Linux, Kali Linux (as applicable)
- **Security Telemetry:** Windows Event Logs, Wazuh Agent
- **Security Concepts:** Log Analysis, Alert Triage, Threat Detection, Incident Response
